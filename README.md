# dsh-deepseek-balance
A plugin to show balance in Deepseek Harness Web version.

在Deepseek Harness网页端展示余额信息。

# How to use

Just install this plugin and it will display your Deepseek account balance info beside the composer's token-usage stats.

在Deepseek Harness中安装本插件后，会话的输入框下方会展示你Deepseek账号的余额信息，点击可以查看详情。
